# Square Star Pattern Logic

1. Use an outer loop to control the number of rows.

2. Use an inner loop to print stars in each row.

3. The outer loop runs from `1` to `size`.

4. The inner loop also runs from `1` to `size`.

5. Print `*` inside the inner loop.

6. After printing one complete row, move to the next line.
