Sum of Array Elements Logic

Suppose array elements are:

10 20 30 40 50

We need to find:

10 + 20 + 30 + 40 + 50

Output:

150
Step 1

Declare a variable:

sum = 0

This stores total sum.

Step 2

Use a loop to read array elements.

Store elements using:

arr[i]
Step 3

Inside loop:

sum = sum + arr[i]

Meaning:

add every array element into sum.

Process

Suppose array:

10 20 30

Calculation:

sum = 0 + 10 = 10
sum = 10 + 20 = 30
sum = 30 + 30 = 60
Main Idea

Loop:

visits every array element

Then:

continuously adds elements into sum.
