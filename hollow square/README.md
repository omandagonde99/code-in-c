# Hollow Square Pattern Logic

1. Use an outer loop to control rows.

2. Use an inner loop to control columns.

3. Print `*` only on the border positions:
   - first row
   - last row
   - first column
   - last column

4. Print space `" "` for inner positions.

5. Move to the next line after completing each row.

# Condition Used

if(i == 1 || i == size || j == 1 || j == size)
