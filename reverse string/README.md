# Reverse String Logic

1. Take a string as input from the user.

2. Find the length of the string using a loop.

3. Continue counting characters until the null character `'\0'` is reached.

4. After finding the length, start traversing the string from the last character.

5. Use a loop from:

   length - 1

   to:

   0

6. Print each character one by one while moving backward.

7. The characters printed in reverse order form the reversed string.

# Example

Original String:
Hello

Reversed String:
olleH

# Main Concept

- Strings are stored as character arrays.
- The null character `'\0'` represents the end of the string.
- Reversing a string means printing characters from the last index to the first index.
