# Copy One Array to Another Logic

1. Take the size of the array from the user.

2. Use a loop to store elements in the first array.

3. Create another array to store copied elements.

4. Use a loop to copy elements from the first array to the second array.

5. Copy each element using:

   arr2[i] = arr1[i]

6. Repeat the process until all elements are copied.

7. Print the elements of the second array.

# Example

Original Array:
10 20 30 40 50

Copied Array:
10 20 30 40 50

# Main Concept

- Arrays are copied element by element.
- The same index position is used in both arrays.
- Each value from the first array is stored in the second array.
