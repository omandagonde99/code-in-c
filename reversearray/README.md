# Reverse Array Logic

1. Take the size of the array from the user.

2. Use a loop to store array elements.

3. Start another loop from the last index of the array.

4. Print elements from:
   
   size - 1 to 0

5. Decrease the index in every iteration using `i--`.

6. This prints the array elements in reverse order.

# Example

Array:
10 20 30 40 50

Reverse Array:
50 40 30 20 10

# Main Concept

- Arrays start indexing from `0`.
- The last index of an array is `size - 1`.
- Traversing from the last index to the first index reverses the array output.
