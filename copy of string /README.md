# Copy String Logic

1. Take a string as input from the user.

2. Create another string to store the copied data.

3. Use a loop to traverse the original string character by character.

4. Continue the loop until the null character `'\0'` is reached.

5. Copy each character using:

   str2[i] = str1[i]

6. Increase the index after copying each character.

7. After the loop ends, copy the null character to the second string.

8. Print the copied string.

# Example

Original String:
Hello

Copied String:
Hello

# Main Concept

- Strings are copied character by character.
- The null character `'\0'` marks the end of the string.
- Copying continues until the null character is reached.
