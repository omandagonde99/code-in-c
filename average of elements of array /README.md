# Find Average of Array Elements Logic

1. Take the size of the array from the user.

2. Use a loop to store array elements.

3. Initialize `sum = 0`.

4. Add all array elements into `sum`.

5. Divide the total sum by the number of elements.

6. Store the result in `average`.
